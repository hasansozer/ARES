### ARES

Welcome to the web page of the ARES project. This project aims at developing **an evolutionary adversarial self-play framework** in which LLM-based agents iteratively challenge and improve one another. By combining **adversarial dynamics with evolutionary optimization**, ARES seeks to push beyond the limitations of static training and produce models that are robust, adaptive, and effective for software analysis tasks.

The ARES project is hosted by [Ozyegin University](https://www.ozyegin.edu.tr/) and carried out in collaboration with [SINTEF Digital](https://www.sintef.no/en/digital/). The project runs from November 2026 to November 2029.

You can find software tools, source code, datasets and other relevant artifacts at the GitHub repositories of the project: the [Ozyegin University repository](https://github.com/hasansozer/ARES) and the [SINTEF Digital repository](https://github.com/merveast/ARES).
